# 🧠 RecallFlow AI

RecallFlow AI is an intelligent visual memory assistant built with Python and Streamlit. It helps users capture screenshots/notes, extract tasks via OCR, manage reminders, explore memory connections, and perform grounded Q&A over personal archives.

## 🚀 Features
- **Visual Memory Capture:** Upload images/notes and store structured metadata locally.
- **Local OCR Integration:** Extracts text using Tesseract OCR.
- **Smart Task Extraction & Management:** Automatically extracts tasks, priorities, and due dates with a full review checklist, editing, and deletion support.
- **Daily Briefing & Smart Planning:** Organizes overdue, due today, and upcoming tasks into an optimized schedule.
- **Grounded QA ("Ask Your Memories"):** Answers questions strictly grounded in saved records with verbatim evidence snippets.
- **Memory Connections:** Discovers related memories and linked tasks using keyword overlap and scoring thresholds.
- **Secure Deletion:** Permanently removes memories and associated files while preserving linked task histories.

## 🛠️ Tech Stack
- **Python / Streamlit** (Frontend & Backend UI)
- **Tesseract OCR** (Text extraction)
- **JSON-based local storage** (Lightweight persistence)
